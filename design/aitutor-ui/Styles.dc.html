Gaps read as unfilled, never as red. A gap is information, not a warning — the moment it feels like a telling-off, students start gaming it.

Rules
—Hairlines at 1px, never a drop shadow.
—Radii: 5px chips, 7px controls, 10px panels.
—Spacing on a 4px base; 40px page gutters.
—Logical inline start/end throughout, so an Arabic build mirrors without redrawing.
—No streaks, badges, scores or nudges anywhere in the product.
