Why does the Clausius inequality become an equality for a reversible process?

Session 5 introduces it as ∮ δQ/T ≤ 0, and the ≤ comes from entropy generated inside the system. Slide 12 names the two causes — a finite temperature difference across the boundary, and friction — and says both vanish only if every step is reversible.

So the generated term drops out and it closes to an equality.

PHYS 214 — LECTURE 5
The Clausius inequality
·For any cycle, ∮ δQ/T ≤ 0.
·The inequality is entropy generated inside: finite ΔT at the boundary, and friction.
·Both vanish only if every step is reversible.
·This is what lets us define S as a state function.
